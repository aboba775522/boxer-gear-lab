# Техническое задание: BoxerGearLab

## 1. Цель проекта
Разработка и деплой веб-сервиса для подбора боксерской экипировки (перчатки, шлемы, капы, бинты) на основе параметров пользователя.

## 2. Роли пользователей
- Гость / Пользователь: прохождение теста, получение текстовых рекомендаций и подборки товаров.
- Администратор: управление каталогом экипировки и правилами подбора.

## 3. Модели данных
- EquipmentItem (товары, характеристики, реферальные ссылки)
- UserQuizProfile (параметры пользователя)
- RecommendationRule (правила подбора)

## 4. Ключевой функционал
- Опросник с вопросами про вес, опыт и цели
- Сохранение ответов в Cookies/сессиях
- Интеллектуальный подбор экипировки из БД
- Реферальные ссылки для покупки (НЕ ФАКТ)

## 5. Внешние интеграции / Аналитика
- Pandas для аналитической фильтрации и ранжирования товаров
